# 🎓 Mentor AI: Personalized Student Mentor

[![MongoDB](https://img.shields.io/badge/Database-MongoDB-brightgreen?style=flat-square&logo=mongodb)](https://www.mongodb.com/)
[![AI](https://img.shields.io/badge/AI-Gemini%20%2B%20Grok-orange?style=flat-square&logo=google-gemini)](https://deepmind.google/technologies/gemini/)

**Mentor AI** is an intelligent, full-stack mentorship platform designed to empower students through personalized career guidance, automated scheduling, and placement-focused preparation. By leveraging state-of-the-art LLMs (Gemini & Grok), it acts as a proactive career coach that adapts to each student's unique progress and goals.

---

## 🚀 Key Features

### 🧠 1. Intelligent AI Mentorship
- **Real-time Career Chat:** Ask questions about job roles, interview tips, or career paths.
- **Multi-Model Fallback:** Uses **Google Gemini** as the primary engine with an automatic fallback to **x.ai Grok** during high-traffic or API downtime to ensure 100% uptime.
- **Context-Aware Guidance:** Maintains a history of conversations to provide relevant and personalized advice.

### 📅 2. Autonomous Weekly Scheduling
- **AI-Generated Plans:** Automatically generates a 7-day optimized schedule based on your current tasks and learning goals.
- **Smart Re-prioritization:** Dynamically updates your daily plan when tasks are added or completed.
- **Failure Prediction:** Backend logic to predict and intercept potential bottlenecks in a student's learning path.

### 💼 3. Placement Readiness
- **Company Insights:** Specific guidance for top-tier tech companies.
- **Interview Prep:** Mock interview questions and technical feedback generated by AI.
- **Progress Tracking:** Visual dashboard to monitor task completion rates and placement readiness scores.

### 🛠️ 4. Task Management
- **Full CRUD Support:** Add, edit, and delete tasks with ease.
- **Status Sync:** Real-time synchronization between the Task list and the Weekly Schedule.
- **Persistence:** Securely stored in MongoDB for access across any device.

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB Atlas or Local Instance
- API Keys: [Google Gemini](https://aistudio.google.com/) & [x.ai Grok](https://console.x.ai/)

### 1. Clone the Repository
```bash
git clone https://github.com/YogeshRajkumar/Personalized-Student-Mentor-Ai.git
cd Personalized-Student-Mentor-Ai
```

### 2. Backend Setup
```bash
cd backend
npm install
```
Create a `.env` file in the `backend/` directory:
```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_super_secret_key
GEMINI_API_KEY=your_gemini_key
GROK_API_KEY=your_grok_key
```
Run the server:
```bash
npm run dev
```

### 3. Frontend Setup
```bash
cd ../frontend
npm install
```
Create a `.env` file in the `frontend/` directory:
```env
VITE_API_URL=http://localhost:5000
```
Run the UI:
```bash
npm run dev
```
